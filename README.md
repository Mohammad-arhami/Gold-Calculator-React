## 📝 About

**Gold Calculator React** is a modern, fully responsive web application for calculating the final price of gold. It takes into account the **daily gold rate**, **weight**, **wage (making charge)**, **seller profit**, and **VAT (value-added tax)** — and updates the result **live** as you type.

This project is a **React + Vite** rewrite of the original vanilla JavaScript version, with a **custom ComboBox** component, **RTL layout**, and a beautiful **Navy & Gold** color palette.

## ✨ Features

### 🟢 Core Features

- 🧮 **Accurate gold price calculation** — formula matches real-world gold pricing
- ⚡ **Live calculation** — results update instantly with every keystroke
- 💵 **Live comma formatting** — prices are formatted as `24,000,000` while typing
- 📊 **Detailed breakdown** — see gold price, wage, profit, VAT, and total separately
- 🎛️ **Custom ComboBox** — select from 1–30% or type any decimal value (e.g., `1.11`)
- ✏️ **Editable profit & VAT rates** — type any value directly
- 🎛️ **Smart defaults** — profit `7%`, VAT `10%`

### 🎨 UI/UX Features

- 🌗 **Navy & Gold theme** — elegant, modern, and easy on the eyes
- 📱 **Fully responsive** — works on mobile, tablet, and desktop
- 🇮🇷 **Full RTL support** — perfect for Persian/Arabic users
- 🔤 **Vazirmatn font** — beautiful Persian typography
- ⚡ **Fast reset button** — clear all inputs instantly
- 🖥️ **Fits the viewport** — no scrolling needed on laptops
