# 💰 Gold Calculator React

A modern gold price calculator built with **React** and **Vite**.
A modern gold price calculator built with React and Vite — with live calculation, RTL support, and Navy &amp; Gold theme.


## ✨ Features
- 🧮 Accurate gold price calculation
- ⚡ Live calculation (no button needed)
- 💵 Live comma formatting
- 📊 Detailed breakdown
- 🌗 Navy & Gold theme
- 📱 Fully responsive
- 🇮🇷 Full RTL support

## 🛠️ Tech Stack
- React 18
- Vite
- CSS3
- Vazirmatn Font

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Mohammad-arhami/Gold-Calculator-React.git

# Navigate to project
cd Gold-Calculator-React

# Install dependencies
npm install

# Start development server
npm run dev
